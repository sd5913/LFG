# Museum Heist · 七个页面的低保真线框

查看 [总览图](overview.svg)，或打开各页面 SVG。画幅统一为 1280 × 720，线框只规定信息层级和位置；颜色、插画与按钮样式可在选定视觉风格后替换。

```text
开始 → 摄像头授权/校准 → 游戏中 ⇄ 途中姿势挑战 → 限时开锁 → 胜利
                                  ↘ 失败 ← 警戒满 / 被持续锁定 / 开锁超时
```

| 页面 | 主要信息 | 主要操作 |
| --- | --- | --- |
| 01 开始 | 游戏名称、一句话玩法、隐私/声音入口 | 开始潜入 |
| 02 摄像头 | 预览、上半身取景框、检测状态、3 步准备 | 开始试动作；权限失败时重试授权 |
| 03 游戏中 | 当前目标、展厅、掩体、保安视线、警戒、摄像头小预览 | 键盘移动；暂停/设置 |
| 04 姿势挑战 | 危险来源、剩余时间、目标动作、玩家姿势、保持进度、结果后果 | 跟随动作并保持 |
| 05 开锁 | 3 步动作顺序、当前动作、倒计时、保持进度、摄像头预览 | 依次完成动作 |
| 06 胜利 | 结果、用时、结局图 | 再玩一次 / 返回开始页 |
| 07 失败 | 具体原因和改进提示 | 重试 / 返回开始页 |

待开发与试玩确认的内容：姿势挑战实际次数、开锁时限、失败后从本段还是整个关卡重试，以及是否提供非摄像头演示模式。线框中的数字是示意值。

`generate-wireframes.js` 是源文件，从仓库根目录运行 `node design/ui/wireframes/generate-wireframes.js` 可重新生成全部 SVG。
