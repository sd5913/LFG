# 警官追击：石头剪刀布

本地预览：在此文件夹运行 `node server.mjs`，打开终端显示的地址。首次摄像头识别需联网下载 MediaPipe 模型。

- **启动摄像头并开始**：每回合倒数 3、2、1，倒数结束锁定识别到的手势，警官每回合重新随机出拳。
- **无摄像头演示**：可点击左下角石头、布、剪刀选择手势，体验完整的三回合流程。
- 共进行三回合，每回合分别记胜、负或平。三回合结束后，你的胜场多于警官才算逃脱成功；总比分相同则重新挑战。未识别到手势的回合可以重试，不计入三回合。

`assets/` 中的警官、玩家 PNG 为透明底，其他 SVG 组件也有透明背景。`scene-background.svg` 是独立场景背景。所有视觉部件可以单独用于游戏集成。
